# Learning Temporal

A hands-on exploration of Temporal, starting with the local TypeScript quickstart and developing into a small music demo-submission app.

The project began while preparing an application for a business development role at Temporal. The initial goal is to understand the product well enough to explain how it works, where it could be useful and what problems it helps businesses address.

It also supports a longer-term interest in software engineering: learning how applications are built, how their components interact and how they handle failures.

## Planned work

- Work through the official local quickstart.
- Experiment with waiting, retries and recovery.
- Apply that learning to a demo-submission workflow connecting fictional musicians and A&R contacts.
- Document decisions, mistakes and lessons as the project develops.

## Learning record

Progress will be recorded through Git commits and short learning notes, with instructions and examples added as they are completed.

## Tools and assistance

The starting example comes from Temporal’s official documentation. Codex provides guidance and coding assistance; notes will distinguish that assistance from my own work and understanding.
